# Renjay & Akhila — Wedding Invitation

A responsive online wedding invitation for Dr. Renjay R.V and Dr. Akhila J Sasi.

The site includes:

- a live countdown to the wedding ceremony
- wedding and reception schedules
- one-tap Google Maps directions
- Google Calendar links and a downloadable calendar file
- a mobile-first layout using the couple's burgundy, ivory, and gold palette

## Local development

Requires Node.js 22.13 or newer.

```bash
pnpm install
pnpm dev
```

Create a production build with:

```bash
pnpm build
```
